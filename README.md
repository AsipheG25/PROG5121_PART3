PROG5121 Part 3 – QuickChat

Description
This project is Part 3 of the PROG5121 Programming module. It builds on the QuickChat messaging application developed in Part 1 and Part 2 using Java.

Features
- User login and authentication.
- Sending messages to recipients.
- Message validation.
- Generating unique message IDs and message hashes.
- Storing messages in a JSON file.
- Managing sent, stored and disregarded messages.
- Searching and displaying message information.

Technologies Used
- Java
- Apache NetBeans IDE
- Maven
- JUnit

How to Run
1. Open the project in Apache NetBeans IDE.
2. Allow Maven to load the project dependencies.
3. Run the main class.
4. Log in using the registered user details.
5. Follow the menu instructions to use the application.

Menu Options
The application provides menu options that allow users to send messages, access stored messages and manage their messages.

Message Storage
Messages are stored and managed using arrays and JSON file storage.

Testing
JUnit tests are used to test the application's methods and functionality.
